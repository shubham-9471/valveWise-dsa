# Backend data

The three small fixtures (`ring6`, `grid4x4`, and `tree_bridge`) are hand-made
and keep isolation valves in companion `.valves` files so the `.inp` files
remain valid EPANET inputs. `net_image3.valves` follows the same rule.

`Net1.inp` is copied from
`OpenWaterAnalytics/epanet-example-networks/epanet-tests/network_one/NET1.inp`.
`Net3.inp` is copied from
`OpenWaterAnalytics/epanet-example-networks/epanet-tests/small/st-net3.inp`.
Their generated companions use seeds 41 and 43 with density 0.35.
